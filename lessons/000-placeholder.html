What a lesson is made of

A lesson is short, self-contained, and built around retrieval practice: it asks for an answer from memory before it shows one. It is judged against the mission — Danger 5 solo on every archetype, by derivation rather than recall — and against nothing else.

  1. A framing paragraph: what this concept lets you decide mid-run.
  2. The model itself, in as few numbers as will carry it.
  3. Recall prompts, answered from memory before the answer is revealed.
  4. One source to read next, and the reference docs this builds on.
