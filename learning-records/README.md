# Learning records

A learning record is written when the player's **model of the game** changed —
a heuristic disproved, JPot's advice contradicted by the data, a stat that had
been over-bought revealed as a trap.

It is **not** written for an ordinary mistake, a missed execution, or a run that
simply went badly. Those end in the one change on the run record and nothing
more. One learning record per review would bury the signal, which is the whole
reason the bar is this high.

`/brotato-review` proposes one only when something in it actually changed, and
the proposal can be declined.

## Shape

`NNN-short-slug.md`, numbered in order:

```markdown
# 004 — Armour past 20 is not what keeps me alive at Danger 5

**Date:** 2026-08-31
**From:** run `20260830T193810Z-character_crazy`

## What I believed

...one paragraph, in the player's own words.

## What the data said

...the evidence, with the run and the numbers it came from.

## What I now believe

...the revised model, stated so that a future run can contradict it too.
```

Cite what the change rests on: a run record, a reference doc, a research pass in
`docs/research/`. A record that cannot be checked later cannot be corrected
later.
