# Resources

The sources this workspace's claims are grounded in. Every claim in a lesson or a reference
doc cites one of these, so that a claim can be checked and so that a stale claim is traceable
when a patch lands.

**Patch these sources are read against**: Brotato 1.1.12.0 (see `MISSION.md`).

## How a source is recorded

One entry per source, under the topic it covers:

```
### <name>
- **Link**: <url>
- **Dated / versioned**: <date last checked, and the game version the source describes>
- **Why trusted**: <what makes it authoritative — extracted game data, developer output,
  maintained wiki, a named human with stated experience>
- **Covers**: <which topics below it is cited for>
- **Known limits**: <what it gets wrong, omits, or is stale on>
```

Rules that hold for every entry:

- **No Reddit.** The search tool blocks the domain outright, so a Reddit link cannot be
  re-checked later and is not admissible here.
- **Dated or versioned, always.** An undated source cannot be told apart from a stale one.
- **Disagreements are recorded, not resolved.** Where two sources conflict, the conflict goes
  in _Open questions_ below and stays there until data settles it.
- **The coach is not listed here.** The coach's heuristics live in `NOTES.md` as a named
  source, and are cited from there where they bear on a topic.
